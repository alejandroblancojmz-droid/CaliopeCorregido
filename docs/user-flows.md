# User Flows - Caliope

## Estructura general de navegación

- Inicio
- Login
- Registro
- Feed principal
- Publicación de historias
- Vista de historia
- Perfil de usuario
- Foros
- Acerca de nosotros
- Contacto

---

## Flujo de usuario

Inicio → Login/Registro → Feed principal → Historia → Comentarios → Perfil

---

## Descripción de pantallas

### Inicio
Presentación de la plataforma y acceso a login/registro.

### Feed principal
Historias de la comunidad.

### Vista de historia
Contenido + comentarios.

### Perfil
Historias del usuario + info básica.

### Contacto
Formulario o información del equipo.
